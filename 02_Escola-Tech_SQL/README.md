# 📊 Projeto Escola Tech — SQL e SQLite

Projeto acadêmico desenvolvido durante a atividade **Missão: Analista de Banco de Dados**, com o objetivo de praticar conceitos fundamentais de SQL utilizando SQLite e o DB Browser for SQLite.

O projeto simula a rotina de manutenção, auditoria, tratamento e análise de dados de uma instituição de ensino.

---

## 🎯 Objetivo

Desenvolver conhecimentos práticos de SQL por meio de um banco de dados acadêmico, realizando operações de:

- criação de tabelas;
- importação de dados;
- auditoria;
- correção cadastral;
- inserção de novos registros;
- limpeza de dados;
- alteração da estrutura do banco;
- geração de relatórios;
- classificação de alunos;
- documentação dos resultados.

---

## 🛠️ Tecnologias utilizadas

- **SQLite**
- **DB Browser for SQLite**
- **SQL**
- **CSV**
- **Git**
- **GitHub**
